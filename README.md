# Intelligent Test Execution & Reporting Framework

## Overview

This project implements an automated software testing framework that supports:

* Unit Testing
* Integration Testing
* System Testing

The framework also includes test execution, flaky test detection, and visualization of results.

## Objectives

* Ensure software quality through multiple testing levels
* Automate test execution and reporting
* Detect unstable (flaky) tests

## Technologies Used

* Python
* pytest
* Matplotlib

## Testing Strategy

This project follows a full-stack testing approach:

* Unit Testing: Testing individual components
* Integration Testing: Testing module interactions
* System Testing: End-to-end validation

## How to Run

```bash
pip install -r requirements.txt
python framework/run_tests.py
python framework/visualizer.py
```

## Features

* Automated test execution
* Flaky test detection
* Graph visualization
* Test reporting
